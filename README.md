# BTS TP Pilot V2

Cette version ajoute la logique complète sur 2 ans.

## Principales nouveautés
- Chaque promotion possède une 1re année et une 2e année.
- La promotion 2025-2027 contient déjà une 1re année 2025-2026 considérée comme réalisée.
- La promotion 2026-2028 est en 1re année 2026-2027.
- La progression pédagogique reste disponible sur 2 ans.
- Génération à la demande : 1re année, 2e année ou 2 ans complets.
- Filtrage par U5/U6/U7/U8.
- Génération complète, version inspection ou réalisée uniquement.
- Archivage d’une promotion complète sans perdre son historique.
- Les archives peuvent être rappelées plus tard.
- Drive BTS et Classroom intégrés par liens.
- Sauvegarde locale + export/import JSON.
